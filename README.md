# 🚀 Mehmet Doğruer | Kişisel Portfolyo Web Sitesi

Bu proje, bir bilgisayar mühendisliği öğrencisi olarak teknik yetkinliklerimi, projelerimi ve gelecek vizyonumu sergilemek amacıyla geliştirilmiş **tek sayfalık (single-page)** statik bir web sitesidir.

## 📋 Proje Hakkında
Bu web sitesi, Karabük Üniversitesi'ndeki laboratuvar dersim kapsamında, modern web standartlarına uygun olarak tasarlanmıştır. Projenin ana odak noktası, **JavaScript kullanmadan** sadece saf HTML ve CSS ile profesyonel bir kullanıcı deneyimi sunmaktır.

## 🛠️ Teknik Özellikler
*   **Dil:** HTML5 & CSS3
*   **Tasarım Yaklaşımı:** 
    *   **Dark Mode:** Göz yormayan, modern 'developer' estetiği.
    *   **Responsive:** Flexbox ve Grid sistemleri ile mobil, tablet ve masaüstü uyumlu yapı.
    *   **No-JS:** Etkileşimler ve görsel düzen tamamen CSS mimarisi ile kurulmuştur.
    *   **Smooth Scroll:** CSS `scroll-behavior` ile yumuşak sayfa içi geçişler.

## 📂 Sayfa Yapısı
Site aşağıdaki temel bölümlerden oluşmaktadır:
1.  **Hero:** Modern bir karşılama ve profesyonel başlık.
2.  **Hakkımda:** Eğitim hayatım ve teknolojiye bakış açım.
3.  **Yetenekler:** Java, C, Python, SQL ve Web Teknolojileri üzerine teknik yetkinliklerim.
4.  **Projeler:**
    *   **Atalay Manav:** Yerel işletme odaklı web arayüz projesi.
    *   **Hicaz Hyperloop:** CAN bus haberleşme protokolü üzerine gerçekleştirdiğim teknik çalışmalar.
